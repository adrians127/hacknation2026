# @hacknation/api-client

A typed HTTP client generated from `@hacknation/contracts/openapi.json`. The `paths` / `components` types are generated by **openapi-typescript**, and **openapi-fetch** runs at runtime (a thin wrapper over `fetch`, about 6 kB).

```ts
import { createApiClient, type Schema } from "@hacknation/api-client";

const client = createApiClient("http://localhost:3001/v1", { credentials: "include" });
const { data, error } = await client.GET("/health");   // data: Schema<"HealthResponse">
```

The frontend wraps it in TanStack Query hooks via `openapi-react-query` (`apps/frontend/src/api/client.ts`).

## Generation

```bash
pnpm generate     # from the repo root: contracts -> openapi.json first, then this package
```

`src/generated/openapi.d.ts` is committed, and CI checks that it is up to date. Do not edit it by hand.

## Why this package uses TypeScript 6

The rest of the repo uses TypeScript 7 (native `tsgo`). The `typescript@7` package no longer ships the classic JS API (its main export is just `lib/version.cjs`), and `openapi-typescript` needs it (peer `typescript`). That is why **only this workspace** has `typescript@6.0.3` in its devDependencies. pnpm resolves the peer from this package, so the rest of the repo stays on TS 7. `pnpm peers check` reports a warning (`openapi-typescript` declares `^5.x`), but generation works correctly. Once `openapi-typescript` supports TS 7, bump the version and remove this exception.
